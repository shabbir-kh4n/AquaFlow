# Preset avatars

The 36 SVGs in this folder were generated once, offline, with [DiceBear](https://www.dicebear.com)
(`@dicebear/core` 9.4.3 + `@dicebear/collection` 9.4.2). DiceBear is not a runtime dependency of the app.
Background colours were set to tints from the app's green palette (`src/styles/theme.css`).

| Folder      | Role             | Style      | Design by                                   | Licence |
|-------------|------------------|------------|---------------------------------------------|---------|
| `resident/` | Resident         | Lorelei    | Lisa Wischofsky (remixed by DiceBear)       | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| `admin/`    | Community admin  | Notionists | Zoish (remixed by DiceBear)                 | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| `system/`   | System admin     | Thumbs     | DiceBear                                    | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

The DiceBear library code itself is MIT-licensed; the artwork of these three styles is CC0 1.0
(public domain dedication), as stated in each style package's README and in the `<metadata>` block
embedded in every SVG. See https://www.dicebear.com/licenses for the upstream overview.

Avatar keys map to files as `resident-07` -> `resident/07.svg`, `admin-03` -> `admin/03.svg`,
`system-12` -> `system/12.svg`.
